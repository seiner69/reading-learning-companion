# 忠实原文的伴读

## 先定位，再讲解

使用用户提供的具体版本。PDF 的文件页序与印刷页码可能不同；分别写明两个坐标，并说明采用 1 起始页序还是工具返回的 0 起始索引。偏移量只适用于核对过的区间，不能假设整本书都固定。

EPUB、网页和无页码文本用章名、小节名、段落或短锚点定位。不要为无页码材料编页码，也不要在换版本后直接复用旧页码。

根据约定选择连续范围，先读取该范围。图片、图注、公式可能携带正文没有的信息；无法读取时说明缺口，而非凭附近文字猜图中细节。若材料缺失，不把通用主题讲解标成该页内容。

## 分开四类内容

1. 材料在当前范围明确提出的命题、论证和例子。
2. 为了理解所作的中文解释；保留关键英文术语以便回查。
3. 材料范围之外的背景、最新研究或另外的案例；明确标为补充并在需要时查证。
4. 仍待检验的推测或类比；说明哪里可能不成立。

通常先完成前两类，第三、四类按用户需求加入。用户只要求伴读时，不因某个术语适合讲一整门课就跳过后续原文。

材料没有给出机制答案时，明确“这里提出问题，尚未给出答案”。旧教材中的历史性表述与现今事实分开；无法核对最新情况，不擅自把旧描述改为当前共识。

## 降低语言与概念负担

讲清术语指向的对象、变量关系、必要前提，再给例子。遇到公式，解释符号和关系为何这样写；不能只用公式替换解释。

阅读英文材料不等于训练英语。用户主要想理解内容时，中文解释为主，只保留对照查阅所需术语。用户明确要翻译、语言学习或精读句法时再调整。

先补理解当前论证实际需要的最少基础，再使用依赖这些基础的术语、公式或定理。例如使用比率前解释分子、分母和比较对象；不把“最少”理解为省略关键前提，也不展开与当前论证无关的预备课程。

用户要求保留领域的正式概念、关键词、定理或原理时，给出名称、含义及成立条件；易懂的解释不能代替它们，也不能凭通俗类比虚构定理。

用户说“太复杂”时可缩小单个解释步骤、减少同时引入的概念，并提供一个可检查的例子；不要再加一套更庞大的方法论。解释步骤的大小与本轮覆盖范围是两件事：用户要求完整一章时，把必要基础嵌入原文论证，不能讲完一个基础例题就宣称完成整章，或擅自改成每轮一小段。

按已读取的标题与论证节点核对覆盖情况；未读、缺失或因篇幅尚未讲到的部分明确列为未完成，保留续读锚点。不要用长篇逐段复述或复制受保护正文来代替论证覆盖。

## 保持连续性

批量从两页改成四页，只改变下一轮范围大小，不重置位置，也不把已读页再算一次。例：上轮确认覆盖印刷页 8—9，下一轮四页即 10—13；前提是定位和材料可读取。

插入的例题或讨论结束后，回到先前正文锚点。输出记录“已讲解到哪里”与“下一处从哪里开始”，不宣称学习者已经掌握整章。
